🚀 Terminal Trainer

Interactive command line learning in your browser

terminal-trainer@web:~$
$

Available Commands

  • help - Show available commands
  • quiz [topic] - Start a quiz (linux, git, docker, kubectl, vscode)
  • cheat [topic] - Show cheat sheet
  • clear - Clear terminal

Available Topics

  • linux - Basic Linux commands
  • git - Git version control
  • docker - Docker containerization
  • kubectl - Kubernetes management
  • vscode - VS Code shortcuts
